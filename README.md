 ProjUp: E-Commerce Web Application

A responsive e-commerce web application where users can browse products by category, search for items, view product details, and manage a shopping cart.

Live Demo: https://projup-app.vercel.app

 Features

- Browse all products on the home page
- Filter products by category (sidebar and header navigation)
- Real-time product search
- Product detail view with quantity selector, Add to Cart and Buy Now buttons
- Shopping cart: add, remove, update quantity, clear cart
- Cart badge showing total items and total price calculation
- Auto-sliding banner
- Responsive design for mobile and desktop

 Tech Stack Used

- ReactJS (Vite)
- JavaScript
- Tailwind CSS
- Zustand (state management)
- Axios
- React Icons
- DummyJSON API (https://dummyjson.com)
- Deployed on Vercel
